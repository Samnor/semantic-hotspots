# Security

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/Samnor/semantic-hotspots/security/advisories/new). Avoid disclosing exploit details, credentials or model contents in public issues.

The latest release receives fixes. The package does not upload models or reports. Static analysis and data generation operate on local inputs; the optional benchmark command launches a user-selected DAX Studio executable and connects to the explicitly supplied endpoint.

Treat semantic models and generated reports as potentially sensitive: they can contain business logic, object names, identifiers and source paths. Use fictional or sanitized examples when sharing a reproduction.
