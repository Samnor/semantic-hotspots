Import recorded timings (optional)

Choose a native Power BI Performance Analyzer JSON export. Recorded DAX query contexts are shared by their measures; they are not isolated measure cost. The recording is matched offline and does not verify model identity.

Engine client setup

On Windows, install this release with its optional [engine] extra into the same virtual environment. A compatible official Microsoft ADOMD SDK is also required. The setup button explicitly downloads the pinned official x64 .NET Framework client, verifies its checksum and installs it in your local cache. No model data is sent.
